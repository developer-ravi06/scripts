# 🔧 Automation Scripts for Windows, VMware & Linux

Level up your admin toolkit with a hand-picked suite of PowerShell and shell scripts — tailor-made for Windows administrators, VMware vCenter virtuosos, and Linux operators.

## What’s Inside?  

1. 📸 **VM Snapshot Creator**  
   • Instantly spin up one or dozens of vCenter VM snapshots in a single command.  

2. 🗑️ **VM Snapshot Remover**  
   • Clean up aged or unwanted snapshots—one VM or your entire inventory.  

3. 🌐 **Internet Explorer Proxy Setter**  
   • Roll out corporate proxy settings across workstations with zero GUI clicks.  

4. 💽 **Disk Usage Auditor**  
   • Quickly scan drives on Windows or Linux and get a clear map of your disk consumption.  

5. 🔒 **Linux Password Validator**  
   • Run a batch check against `/etc/shadow` to ensure all Linux accounts meet your security policy.
